    Organizations & Projects

    Chakra Console organises customers in a two-level hierarchy: organisations own one or more projects.

    Organisations

    An organisation represents a customer company. It holds:

    • A single package that applies to every project under it.
    • One Chakra Console sign-in — the organisation user can see all its own projects and nothing else.

    Only Chakra Labs admins (listed in ADMIN_USERS) can create or edit organisations.

    Creating an organisation

    1. Open Organizations in the left sidebar.
    2. Click New Organization.
    3. Enter the company name, contact email, and assign a package.
    4. A sign-in credential (email + password) is created for the organisation user. Share it securely.

    Projects

    A project is one conversational AI deployment. It maps 1-to-1 with a row in the licenses table and has its own licence key.

    Each project carries:

    Field Description
    Licence key Unique token authenticated by the license server. Shown once; stored as a SHA-256 hash.
    Project type (channels) phone, web_voice, web_chat — any combination. Signed into the licence payload; chakra-convai 0.8+ rejects sessions on unlisted channels. Empty = all channels allowed.
    Voice pipeline e.g. gemini_live, chakra_voice, twilio_voice.
    Voice Gemini voice name for gemini_live pipelines (blank = app decides).
    Greeting mode recorded plays a pre-uploaded audio clip; auto generates a greeting; blank = app handles it.
    Daily talk time Per-caller limit in seconds (0 = unlimited). chakra-convai 0.5+ enforces it.
    Google access gateway = project holds no Google key; Gemini Live sessions must call /v2/gemini-token.

    Creating a project

    1. Navigate to the parent Organization → Projects tab.
    2. Click New Project.
    3. Configure the project type, pipeline, and voice.
    4. Copy the licence key shown on creation — it cannot be retrieved later.

    Editing a project

    All fields except the licence key are editable. Changes take effect at the next chakra-convai startup (or key re-verification).

    Project type card

    When you open a project, the Project Type card shows the exact CLI flags needed to match your channel selection:

    # Phone-only project
chakra-convai init --channels phone

# Multi-channel: phone + web voice
chakra-convai init --channels phone,web_voice

# Web chat only
chakra-convai init --channels web_chat

    Migration from pre-organisation licences

    Before 2026-10-12, each licence stood alone with its own package and sign-in. On first hub load after the upgrade, the hub automatically:

    1. Groups licences by company name into organisations.
    2. Creates one organisation sign-in per company (the old per-licence credential is promoted).
    3. Assigns the licence's existing package to the organisation.

    Existing credentials continue to work without any action needed.
