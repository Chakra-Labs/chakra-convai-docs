    License Server API

    chakra-license-server is a FastAPI microservice that is the authoritative licence gate for all chakra-convai deployments. Every engine call goes through it.

    Base URL (production): https://license.chakralabs.lk (behind Caddy on the fleet control host).

    POST /v2/verify

    Verifies a licence key and returns a signed JWT-style payload the engine stores for the session duration.

    Request

    {
  "token": "ck_live_xxxxxxxxxxxx",
  "nonce": "random-string-per-call"
}
    Field Type Description
    token string Plaintext licence key
    nonce string Random value to prevent replay

    Response 200 OK

    {
  "payload": "<base64-encoded JSON>",
  "signature": "<base64 Ed25519 signature>"
}

    The decoded payload contains:

    {
  "license_id": 42,
  "is_active": true,
  "package": "National Plus",
  "channels": ["phone", "web_voice"],
  "pipelines": ["gemini_live", "chakra_voice"],
  "daily_limit_seconds": 3600,
  "limit_warning_seconds": 300,
  "gemini_voice": "Aoede",
  "greeting_mode": "recorded",
  "greeting_id": "greet_abc123",
  "greeting_text": "Welcome to Acme support.",
  "google_access": "gateway",
  "key_hash": "sha256:...",
  "nonce": "random-string-per-call",
  "issued_at": 1728900000
}

    Error responses

    Code Meaning
    403 Key not found, inactive, or channel mismatch
    503 Database unavailable

    POST /v2/gemini-token

    Issues a one-session Gemini Live ephemeral token for projects where google_access = gateway (the project holds no Google API key).

    Request

    {
  "token": "ck_live_xxxxxxxxxxxx",
  "nonce": "per-session-nonce",
  "agent": "optional-agent-label"
}

    Response 200 OK

    {
  "token": "auth_tokens/...",
  "expires_at": "2026-10-16T18:00:00Z",
  "api_version": "v1alpha"
}

    Rate limiting

    Up to 120 tokens per licence per minute. A single session renewal counts as one token. Exceeds 429.

    Error responses

    Code Meaning
    403 Inactive licence
    409 Project uses its own key / no Gemini key stored / Gemini Live not in pipeline
    429 Rate limit exceeded
    502 Google refused to issue token

    POST /track-usage

    Records a finished session against the licence. Called by chakra-convai after every call or chat.

    Request

    {
  "token": "ck_live_xxxxxxxxxxxx",
  "seconds": 142.5,
  "pipeline": "gemini_live",
  "session_type": "phone"
}
    Field Type Options
    session_type string phone, web_voice, web_chat
    pipeline string gemini_live, chakra_voice, twilio_voice, unknown
    seconds float Duration of the session in seconds
    tokens object {input, cached, output} — for web_chat only

    Response 200 OK

    {
  "status": "updated",
  "total_minutes": 1234
}

    Web chat sessions return "status": "updated" with "session_type": "web_chat" instead of total_minutes.

    Running locally

    cd chakra-license-server
pip install -r requirements.txt
cp .env.example .env    # fill DATABASE_URL and SIGNING_KEY
python init_db.py       # creates tables, applies migration 001
uvicorn main:app --port 8000 --reload

    Environment variables

    Variable Description
    DATABASE_URL PostgreSQL connection string (Neon or local)
    SIGNING_KEY Ed25519 private key (base64) for payload signing
    GEMINI_TOKEN_MOCK Set to 1 in tests to skip real Google calls

    Docker

    docker build -t chakra-license-server .
docker run -p 8000:8000 --env-file .env chakra-license-server

    In production it runs behind Caddy on the fleet control host alongside chakra-license-hub.
