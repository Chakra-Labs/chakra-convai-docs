    License Management

    Licences are the unit of deployment for chakra-convai. Each project has exactly one licence key that the engine presents on startup and after every call.

    Licence key lifecycle

    Created (key shown once)
       │
       ▼
  Active ──────────────────────────────────────┐
       │                                       │
  Rotate key (old key expires within 60 s)     │
       │                                       │
  New key shown once ──────────────────────────┘
       │
  Deactivate (is_active = false)
       │
  No sessions accepted

    Keys are shown once only

    When a licence key is created or rotated, the plaintext is displayed once. After that only the first 16 characters are visible. Store it in a secrets manager immediately.

    Licence fields

    Field Type Notes
    key / token_hash SHA-256 of the plaintext key Never stored in plaintext after migration 002
    token_prefix First 16 characters Shown in the dashboard for identification
    is_active boolean Deactivated licences are rejected at /v2/verify
    channels phone, web_voice, web_chat (comma list) Signed into JWT payload; mismatch = 403
    used_minutes integer Incremented by /track-usage after each call
    daily_limit_seconds integer Per-caller daily cap (0 = none)
    limit_warning_seconds integer Seconds remaining when a warning is sent

    Rotating a key

    1. Open the project in the dashboard.
    2. Click Rotate key.
    3. The new plaintext key is shown once — copy it now.
    4. The old key remains valid for up to 60 seconds to allow in-flight sessions to finish, then becomes invalid.
    5. Deploy the new key to all running chakra-convai instances (restart or environment update).

    Deactivating a licence

    • Toggle Active off on the project card.
    • The license server rejects /v2/verify immediately.
    • Ongoing calls are not disconnected mid-session, but no new sessions start.

    Usage tracking

    chakra-convai posts to /track-usage at the end of every call. Usage is accumulated per hour in two tables:

    call_usage (phone & web voice)

    Column Description
    license_id FK to licenses
    hour date_trunc('hour', now())
    pipeline gemini_live, chakra_voice, etc.
    calls Number of calls in that hour
    call_seconds Total audio seconds
    web_calls / web_seconds Web-voice subset

    chat_usage (web chat)

    Column Description
    license_id FK to licenses
    hour Bucket
    chats Number of chat sessions
    chat_seconds Total chat duration
    input_tokens / cached_tokens / output_tokens LLM token breakdown

    Licences page

    The Licences page in the dashboard shows all active and inactive licences across all organisations, with search, filter by status, and a quick link to the parent project. Admins can create a standalone licence here or navigate to an organisation project.
